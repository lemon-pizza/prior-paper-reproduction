코드 9개의 역할

파일역할
run.py전체 재현 진입점. 입력 확인 → 거래·통계 → 독립 검산 → 그래프 → 해시 기록.
prepare.py원가격에서 고정1시차 ADF·월별 선정·Q/Z 특징 재생성. 선택되지 않은 전체 후보는 메모리에서만 사용.
engine.py원가격 읽기, 504일 회귀, Q/Z 신호, 달러 배분, 수량·동결·말일 비용 계산.
risk.py주4+기존 보조16 경로의 일별 장부·현금·노출·공분산 분해.
statistics.py20경로×5비용의 성과100행과 주전략 21일 블록 구간.
risk_intervals.py위험 구성 간 차이와 3개월 블록 구간.
verify.py저장 장부에서 수량·현금·비용·손익·통계를 독립 재계산하고 원가격 OLS/ADF/Q/Z 표본 검산.
test_prepare.pyADF 40표본, 작은 그래프 최적매칭, 대표3개월 원가격→특징 재계산 검사.
diagnostics.py결측집계와 동결 비중을 다시 계산하고 가격 불연속·장기결측 PNG/SVG 생성.

재현 명령

이 프로젝트 최상위 폴더에서 실행합니다. 현재 컴퓨터의 검증된 Python을 사용한 명령입니다.

/opt/anaconda3/bin/python final_model/src/run.py

저장된 선정·특징을 이용해 20경로와 통계·검산·진단 그래프를 갱신합니다. 기존 결과는 같은 위치에 다시 저장됩니다.

원가격부터 계산 입력도 다시 만들기

보존된 월별 선정에서 77개월 특징을 다시 계산:

/opt/anaconda3/bin/python final_model/src/run.py --rebuild-features --workers 2

월별 전체 후보 평가와 선정까지 모두 새로 계산:

/opt/anaconda3/bin/python final_model/src/run.py --rebuild-selection --workers 2

전체 선정 재생성은 매칭·정수 최적화 때문에 더 오래 걸립니다. 과거59설정 탐색은 포함하지 않습니다. 선택이 다시 계산되면 해당 특징 캐시는 자동 무효화됩니다.

다른 컴퓨터에서 실행

Python 3.13 환경에서 requirements.txt의 패키지를 설치한 뒤 python final_model/src/run.py를 실행합니다. 가격 다운로드는 필요하지 않습니다. 저장된 입력을 이용하는 경로가 가장 직접적인 재현 경로입니다. 전체 선정 재생성 시 최적화 라이브러리 차이와 동점 처리에 따라 작은 차이가 생길 수 있습니다.

config/model_spec.json은 고정 규칙의 설명입니다. 매개변수를 자동 주입하는 설정 스위치는 아니며 실제 계산 상수는 소스에 고정되어 있습니다.
