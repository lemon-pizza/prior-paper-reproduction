재실행

저장소 최상위 폴더에서 실행합니다. reproduce.py 기본 실행은 해시 검증을 거친 기존 캐시를 재사용해 집계·검산·보고서를 갱신합니다.

python -m pip install -r requirements.txt
python reproduce.py

원가격부터 선정 77개월과 M/B 거래를 전부 새로 계산하려면 --fresh를 사용합니다. 이 명령은 같은 출력 위치의 생성 캐시와 결과를 갱신합니다.

python reproduce.py --fresh --workers 2 --selection-workers 4

기존 결과의 README·HTML·그림만 갱신하려면 python src/report.py를 실행합니다. src/run.py는 하위 실행 경로입니다. 자세한 옵션은 python reproduce.py --help에서 확인합니다. Python·라이브러리 환경은 requirements.txt와 개별 검산 JSON을 참조합니다.
